Why?

Claude Code in Terminal

Run this once. Run it again after a new token.

claude mcp remove --scope user aftercall 2>/dev/null; claude mcp add --scope user --env AFTERCALL_TOKEN={{token}} aftercall -- node /Users/victor/aftercall/apps/mcp/src/main.ts --data-dir '/Users/victor/Library/Application Support/dev.aftercall.app'

Codex config file

Add this to ~/.codex/config.toml, then restart Codex.

[mcp_servers.aftercall]command = "node"args = ["/Users/victor/aftercall/apps/mcp/src/main.ts", "--data-dir", "/Users/victor/Library/Application Support/dev.aftercall.app"]env = { AFTERCALL_TOKEN = "{{token}}" }

Turn this on to get setup commands for Claude Code and Codex, with a fresh token.

Agents can

  • Search and read your meetings
  • Claim an action item, by name
  • Mark an item they claimed as done, with a note

Agents can't

  • Send email or recaps
  • Pay, or touch the agent wallet
  • Change or delete notes
  • Reach meetings while this is off
