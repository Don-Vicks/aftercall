First run

  1. 01 Check your audioPlay something with sound and say a few words. macOS asks for the microphone and system audio here. The test recording is deleted straight away.
  2. 02 Add your NEAR AI keyPaste a key from cloud.near.ai. Aftercall checks it and keeps it in your Keychain. You can record without one; notes wait until you add it.
  3. 03 Record a callStart the call in any app, then press New recording (⌘⇧R) or use the menu bar. Tell everyone you're taking notes; Aftercall asks you to confirm it.
  4. 04 Approve the follow-upsApprove the recap and payments you want. Connect NEAR in Settings when you're ready to pay from your agent wallet.

Build it yourself

Needs Node 24, pnpm 10 and Rust stable. macOS only lets a bundled app capture system audio, so build the app to record, then open the .app it makes.

Read the code on GitHub
Terminal 
git clone [repo URL] aftercall
cd aftercall
pnpm install
pnpm verify      # every check
pnpm --filter @aftercall/desktop tauri build --debug --bundles app
