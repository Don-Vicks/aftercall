# Design source

Copies of the screens and tokens from the Aftercall design canvas (https://claude.ai/artifact/RXNzkVE5TXbVu2ynPKRScW), kept here so the app can be checked against them without access to the canvas. `project/ds/aftercall/tokens.json` is the source for `apps/desktop/src/styles.css`. These are static mockups with sample data, not app code.
