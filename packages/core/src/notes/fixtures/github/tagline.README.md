> A tiny, fast tide-table engine for harbour apps &amp; sailing clubs, written in Rust. It reads NOAA and UKHO feeds and answers "when is high water?" offline, on a phone, in under a millisecond, with no network once the tables are cached for the season.

- Offline first
- No unsafe code
