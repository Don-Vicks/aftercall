# Moonbeam Bikes

[![CI](https://github.com/moonbeam/web/actions/workflows/ci.yml/badge.svg)](https://github.com/moonbeam/web/actions) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

<!-- Keep this paragraph short: it's what the GitHub sidebar can't say. -->
The booking site for **Moonbeam Bikes**: riders pick a bike and a time slot, then pay with [Stripe](https://stripe.com). Built with `Next.js`; the _booking flow_ lives in `app/book`.

## Getting started

```bash
pnpm install
pnpm dev
```
